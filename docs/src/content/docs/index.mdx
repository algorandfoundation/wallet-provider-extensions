## Standalone first, Provider optional

Every package in this workspace is a pure engine or store you can use entirely on its own, such as `createWebKeyStore` for keys, `addAccount` over a plain [@tanstack/store](https://tanstack.com/store) for accounts, `createConnectionsStore` for sessions, and so on, with no `WalletProvider` required. The `WalletProvider` is the optional, first-class composition layer: each package's `With*` extension mounts the same engine on a shared provider when you want several domains in one context. Read [Provider](/concepts/provider/) for how the two modes relate.
